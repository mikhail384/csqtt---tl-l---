# csqtt — VPN-клиент для Android

**csqtt** подключает телефон или планшет к вашему VPS через TURN-инфраструктуру VK. Интернет-трафик выходит с вашего сервера. В приложении также можно развернуть сервер CSQTT, управлять им по SSH и открыть его веб-панель.

Это сборка **mikhail384**, основанная на [CSQTT автора amurcanov](https://github.com/amurcanov/csqtt). Доработки и документация выполнены с помощью **OpenAI Codex / ChatGPT**.

**Текущая версия: 2.5.0.1 · Android 8.0 и новее.**

[**Скачать APK для Android**](https://github.com/mikhail384/csqtt---tl-l---/releases/download/v2.5.0.1/CSQTT-Compatible-2.5.0.1-universal.apk) · [Все файлы выпуска](https://github.com/mikhail384/csqtt---tl-l---/releases/latest)

## Как это работает

Путь подключения: **Android → TURN-сервер VK → ваш VPS → интернет**.

Приложение создаёт VPN на Android и передаёт трафик через TURN к серверу CSQTT. VPS служит точкой выхода в интернет. Само приложение не предоставляет сервер, подписку или готовый доступ к VPN.

## Что понадобится

- Телефон или планшет с Android 8.0+ и доступом в интернет.
- Собственный VPS с сервером CSQTT либо готовая ссылка доступа к чужому серверу, выданная его владельцем.
- Для установки и обслуживания своего сервера — SSH-доступ к VPS с правами root или sudo. Установка рассчитана на Debian/Ubuntu, x86_64 или arm64.
- Данные подключения: ссылка CSQTT, QR-код или параметры сервера. Для автоматического создания звонков через VK потребуется авторизация аккаунта в приложении; при импорте готового доступа способ подключения задаётся его настройками.

VPS можно арендовать, например, через [NodeHost в Telegram](https://t.me/nodehost_bot?start=_tgr_YX3eaKE0Nzdi).

## Установка приложения

1. Скачайте **universal.apk** по ссылке выше. Эта сборка подходит для поддерживаемых архитектур, поэтому выбирать тип процессора не обязательно.
2. Откройте APK на Android. Если система запросит разрешение устанавливать приложения из выбранного браузера или файлового менеджера, разрешите установку и повторите открытие файла.
3. Запустите **csqtt**. Импортируйте ссылку или QR-код доступа либо настройте свой VPS через вкладку **«Деплой»**.
4. На вкладке **«Подкл.»** включите подключение и подтвердите системный запрос Android на создание VPN.

Приложение устанавливается рядом с оригинальным CSQTT от amurcanov. Одновременно на Android может работать один VPN.

**Обновление прежней сборки этого репозитория:** установите APK поверх имеющегося приложения, сохранив его данные. При переходе с версий 2.5.0.5–2.5.0.20 скачайте APK вручную: видимый номер выпуска изменён на 2.5.0.1, а совместимость обновления и подпись сохранены. Удалять установленное приложение перед обновлением не нужно.

## Если своего сервера ещё нет

Откройте **«Деплой»**, укажите адрес VPS, SSH-порт и способ входа. Настройте доступ к панели и запустите установку CSQTT. После установки сохраните ссылку панели и создайте доступ для устройства. Для уже работающего сервера достаточно импортировать выданную ссылку или QR-код.

Приложение поддерживает серверы **CSQTT 2.1.9 и 2.5.0**. Номер Android-сборки 2.5.0.1 не означает, что на VPS нужна такая же версия.

## Подбор скорости

Отключите VPN, сохраните SSH-доступ к тому же VPS во вкладке **«Деплой»**, затем откройте **«Подкл.» → «Пропускная способность» → «Подобрать параметры VPN»**.

Сначала приложение проверяет адреса TURN из встроенного списка. Полные замеры скорости выполняются для отобранных маршрутов, включая штатный DNS-выбор VK и варианты UDP/TCP. Затем сравниваются MTU и потоки. Победитель проверяется повторно перед применением; исходные настройки можно вернуть.

Подбор расходует **до 512 МиБ тестовых данных плюс служебный трафик**. Это измерение пути до VPS, а не обещание такой же скорости на каждом сайте. Результат зависит от оператора, сети телефона, маршрута TURN, нагрузки и канала VPS. DNS в этом сравнении означает выбор TURN по имени, а не замену DNS-сервера для сайтов.

## Экспериментальная функция VK

Переключатель **«Экспериментальная функция»** с подписью **«Завершение звонков VK»** находится в разделе **«Подкл.» → «Пропускная способность»**. До подтверждения информационного окна функция выключена. Окно появляется при каждом включении и сообщает: **«Эффект функции ещё не проверен»**.

Если функция включена и используется аккаунт VK, после 10 минут непрерывной блокировки экрана приложение отправляет команду завершения своих звонков и отключает VPN. После разблокировки создаются новые звонки и восстанавливается подключение. Ручное отключение отменяет автоматическое возобновление.

**Во время паузы VPN не защищает трафик.** Функция не завершает чужие звонки или звонки по импортированным ручным хешам. Успех команды зависит от доступности VK. Влияние на оценку подключений и ограничения аккаунта VK не проверено.

## Что учитывать

- WARP меняет выход трафика на VPS и не гарантирует увеличение скорости.
- Для установки панели через Chrome необходим HTTPS с доверенным сертификатом. Проверка сертификата должна успешно завершаться на вашем сервере.
- Реальные скорость, стабильность и работа VK зависят от сети и внешних сервисов. Локальные тесты сборки не заменяют проверку на вашем устройстве.
